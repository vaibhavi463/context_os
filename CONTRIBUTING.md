# Contributing to ContextOS

Thank you for helping improve ContextOS!

## Workflow Guidelines
1. Fork and create feature branch (`feat/short-description`).
2. Run `make lint` and `make test` before opening PR.
3. Ensure all commits follow Conventional Commits (`feat:`, `fix:`, `docs:`, `ci:`).
4. All PRs must pass automated GitHub Actions CI tests and AI benchmark evaluation.
